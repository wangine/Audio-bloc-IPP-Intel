# Stage 2 MUSIC v0010 baseline

- Source of truth: local `stage2-music-v0010-source.zip` in the working directory, confirmed by the owner. SHA-256: `fac90e5483f7c062b805afcdc4b786397adf5ce4808e025e4fc0bb266bf52d7e`. The archive contains no Git metadata, so its upstream HEAD and branch cannot be recovered. The isolated import commit is `5d96e343f63d6b4d4b058ab3af081b3b2fa094bc` on `candidate/dynamic-recovery-v0010`; it is a new local repository with no remote.
- Baseline runtime: `../stage2-music-v0010`, left untouched. Its `package-manifest.json` says `stage2-music-v0010`, 2 input channels, 3 output channels, 192000 Hz, 1024 frames per block. `EntropyDspEngine.exe` SHA-256 is `4ed07784371b52a2845a15a11e5d3b275c16806552731176b4f3ff45aa03a50e`.
- Actual audio layout: planar IEEE-754 `double`; input 0=L, 1=R; output 0=L, 1=R, 2=CX. The published Stage 2 boundary is 2→3, while the proposed new internal slot is 2→2 on the L/R branch.
- Call path: `DspController::automaticWorker` owns the runtime and calls `DspStageRuntime::step`. The passive subscriber reads a block into two `inputPlanes_`; `TransparentDspExecutor` copies L/R bit for bit to `outputPlanes_` and zeros CX; EQ processes the L/R branch; Center independently receives raw input L/R and writes CX; LRC Aligner processes L/R/CX; publisher and recorder observe output. The native module ABI is `ENTROPY_MODULE_ABI_VERSION=0x00010000`, `entropy_module_get_api`, and planar `EntropyAudioBlockF64`.
- Insertion: one new optional L/R hook after EQ and before LRC Alignment. It must use a separate prepared L/R output buffer when active, because the current output L/R buffer is already owned by the host. When OFF or DLL absent, the host must skip the hook entirely. Center's raw tap and the order of existing modules remain unchanged.
- Existing native loader has an explicit module registry with SHA-256 verification; the package verifier also rejects unknown `.dll` files. Any candidate package must add only the new DLL with its verified hash and keep all existing hashes.
- Scope boundary: Stage 1, Stage 3, Center, LRC Delay Align, clock, sink, SRC, existing StageBus contract and stable runtime stay untouched. The owner subsequently authorized a Stage 2 UI control in the existing Entropy DSP style.
- Unverified at baseline: upstream source commit/tag; whether physical Stage 3 MUSIC playback accepts this candidate; deterministic end-to-end A/B capture; physical DAC underruns/CPU; numerical headroom downstream. No audio playback is initiated by this work.
